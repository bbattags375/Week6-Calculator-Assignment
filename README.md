# Week6-Calculator-Assignment
A simple command-line calculator that performs addition, subtraction, multiplication, and division. The user enters two numbers and an operator, and the result is displayed. Division by zero and non-numeric input are both handled gracefully without crashing the program.
What I Learned

Using try/except to handle runtime errors
The difference between ZeroDivisionError and ValueError
Formatting output with f-strings
Conditional logic with if/elif statements

Tools Used

Python 3

How to Run
Download the file and run the following command in your terminal:
python Week6Calculator.py
